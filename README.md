# Yuki 🌸 — සිංහලෙන් ජපන් ඉගෙන ගන්න

Yuki යනු ශ්‍රී ලාංකික Beginner (N5) ඉගෙනුම්කරුවන් සඳහා සාදන ලද Japanese speaking tutor වෙබ් යෙදුමකි. ඉදිරිපස **vanilla HTML, CSS සහ JavaScript පමණයි**. Demo mode නොමිලේ ක්‍රියා කරයි; සජීවී AI අවශ්‍ය නම් කුඩා Node.js server එකක් වෙනම සකසන්න.

## ඉක්මනින් පටන් ගන්න — API key අවශ්‍ය නැහැ

1. **Node.js 18 හෝ ඊට අලුත්** ස්ථාපනය කරන්න.
2. මෙම project folder එකේ terminal එක විවෘත කරන්න.
3. පහත විධානය ධාවනය කරන්න:

   ```bash
   npm start
   ```

4. බ්‍රවුසරයෙන් **http://localhost:3000** වෙත යන්න. නම ලිවීම විකල්පයි; **“ගමන අරඹමු”** ඔබන්න.

`npm install` අවශ්‍ය නැහැ — server එක Node.js හිම built-in modules පමණක් භාවිත කරයි. `index.html` ගොනුව කෙළින්ම විවෘත කළත් Demo mode ක්‍රියා කරයි. කෙසේ වෙතත් මයික් පහසුකම සඳහා `localhost` හෝ HTTPS හරහා පිවිසීම වඩා සුදුසුයි.

## Demo mode යනු කුමක්ද?

Demo mode එකේ කතාබහ පිළිතුරු **පෙර සකස් කළ ආදර්ශ සංවාද** වේ. ඔබ ලියන වාක්‍යයට අනුව සකස් වන AI පිළිතුරු නොවේ. වැරදි පිළිබඳ සිංහල සටහන් සීමිත, පැහැදිලි නීති කිහිපයකට පමණක් ලබා දෙයි. සියලු වැරදි හඳුනාගනී යැයි නොසිතන්න. වචන කාඩ්පත්, පාඩම්, ප්‍රශ්න, දෛනික අභියෝග සහ ප්‍රගතිය සජීවී AI නැතිවත් භාවිත කළ හැක.

## සජීවී AI සක්‍රිය කරන හැටි (විකල්ප)

1. `.env.example` ගොනුව **`.env`** නමින් පිටපත් කරන්න.
2. `.env` තුළ `OPENAI_API_KEY=ඔබේ_key_එක` ලෙස ඔබේ OpenAI API key එක ඇතුළු කරන්න.
3. අවශ්‍ය නම් `OPENAI_MODEL` වෙනස් කරන්න (පෙරනිමිය `gpt-4o-mini`).
4. Server එක නවත්වා නැවත `npm start` ධාවනය කරන්න. ඉහළ **“AI සකසා ඇත”** ලේබලය පෙනිය යුතුයි. සැබෑ සම්බන්ධතාව පණිවිඩයක් යවා පරීක්ෂා කරන්න.

`.env` නොහදා terminal පරිසර විචල්‍යයක් ලෙසද key එක ලබා දිය හැක:

```bash
OPENAI_API_KEY="your-key-here" npm start
```

**ආරක්ෂාව:** API key එක `script.js`, `index.html`, browser console හෝ public repository එකකට දමන්න එපා. `.env` ගොනුව `.gitignore` තුළ ඇත. Browser එක `/api/chat` වෙත පණිවිඩය යවයි; provider වෙත key සහිත ඉල්ලීම යවන්නේ server එක පමණයි. Server එකේ පණිවිඩ දිග සීමා, මිනිත්තුවකට ඉල්ලීම් සීමා හා timeout තිබේ. සැබෑ AI භාවිතයට provider ගාස්තු සහ අන්තර්ජාලය අවශ්‍ය විය හැක.

## තිබෙන පහසුකම්

- සිංහල පිළිගැනීමේ තිරය, dashboard, Beginner මට්ටම, දින පෙළ සහ XP.
- මාතෘකා 4ක කතාබහ; ජපන් පිළිතුර, romaji, සිංහල අර්ථය හා ව්‍යාකරණ සටහන්.
- සහාය ඇති බ්‍රවුසරවල Japanese speech recognition: මයික් තට්ටු කර කතා කරන්න, නැවත තට්ටු කර නවත්වන්න; පෙළ **පරීක්ෂා කර යවන්න**.
- බ්‍රවුසරයේ Japanese text-to-speech; නැවත අසන්න සහ 0.7×–1.2× වේග සැකසීම.
- වර්ග කළ වචන කාඩ්පත් 18ක්, කාඩ්පත් පෙරළීම, කලවම් කිරීම හා ඉගෙන ගත් වචන සලකුණු කිරීම.
- සිංහලෙන් පැහැදිලි කරන ව්‍යාකරණ පාඩම් 5ක් සහ එක් එක් පාඩමට කුඩා ප්‍රශ්නයක්.
- සවන්දීමේ අභ්‍යාස 5ක්, සෙමින් අසන්න, පිළිතුරෙන් පසු ජපන් පෙළ බලන්න.
- දෛනික අභියෝග 3ක්, ත්‍යාග ලබාගැනීම, responsive mobile menu, dark mode, සැකසුම් හා දත්ත මකා දැමීම.
- ප්‍රගතිය/සැකසුම් browser `localStorage` තුළ පමණක් සුරැකේ; account එකක් අවශ්‍ය නැහැ.

## බ්‍රවුසර සටහන්

Text-to-speech සඳහා `speechSynthesis` සහ මයික් හඳුනාගැනීම සඳහා `SpeechRecognition`/`webkitSpeechRecognition` භාවිත වේ. පහසුකම් බ්‍රවුසරය සහ උපාංගය අනුව වෙනස් වේ. මයික් අවසරය ලබා දිය යුතුයි; සමහර speech recognition සේවා අන්තර්ජාලය භාවිත කළ හැක. හඬ සහාය නැත්නම් සවන්දීමේ ලකුණු නොගණන් ගනී; පෙළ කියවීමට වෙනම විකල්පයක් පෙන්වයි. හොඳ අත්දැකීමකට Chrome/Edge සහ උපාංගයේ Japanese voice එකක් භාවිත කරන්න. Sinhala/Japanese fonts සඳහා online Google Fonts ලබාගැනීමට උත්සාහ කරන අතර, offline නම් පද්ධතියේ font භාවිත වේ.

### ඉක්මන් පරීක්ෂණ ලැයිස්තුව

පිළිගැනීමෙන් ඇතුළු වන්න → dashboard බලන්න → මාතෘකාවක් තෝරා ජපන් පණිවිඩයක් යවන්න → පෙර සකස් කළ Demo ලේබලය බලන්න → කාඩ්පත පෙරළා වචන 3ක් සලකුණු කරන්න → ව්‍යාකරණ ප්‍රශ්නය විසඳා පාඩම අවසන් කරන්න → හඬ අසා පිළිතුරු දෙන්න → අභියෝග ත්‍යාගය ගන්න → dark mode/romaji/වේගය වෙනස් කර පිටුව නැවත විවෘත කර සුරැකුණු බව බලන්න.
